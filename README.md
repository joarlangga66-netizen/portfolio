# Joar Langga — Portfolio

**Live site:** https://joarlangga.vercel.app

My personal portfolio as a Senior Bookkeeper (QuickBooks & Xero, QuickBooks ProAdvisor). It shows my services, experience, client testimonials, credentials, the industries I work with, a short intro video, and a contact section.

## Built with

- HTML, CSS and JavaScript, with no framework or build step
- Responsive layout for desktop and mobile
- Interactive touches: custom cursor effects, hover/click/scroll sound effects and scroll animations
- SEO basics: `robots.txt` and `sitemap.xml`
- Hosted on [Vercel](https://vercel.com)

## Files

| File | What it does |
| --- | --- |
| `index.html` | Page content and structure |
| `styles.css` | Layout, colors and animations |
| `script.js` | Interactions, sound and cursor effects |
| `assets/` | Images, video and icons |
| `Joar_Langga_ATS_Resume.pdf` | Downloadable resume |

## Run locally

Open `index.html` in any browser.
